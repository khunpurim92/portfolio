# แฟ้มผลงาน อ.ดร.ปุริม ศรีสวัสดิ์

เว็บแฟ้มผลงานแบบ static (GitHub Pages) อ่านรายการจาก Google Sheet `_สารบัญผลงาน` และไฟล์จริงจาก Google Drive โฟลเดอร์ `เอกสารประกอบ`

## โครงสร้าง
- `index.html`, `assets/` โค้ดและสไตล์ (ไม่ต้องแก้)
- `config.js` ตั้งค่าเว็บ แก้ไฟล์นี้ไฟล์เดียว
- `data/snapshot.json` สำเนารายการผลงาน ใช้แสดงเมื่ออ่านชีตไม่ได้ (เช่นหลังปิดการเข้าถึง)

## วิธีเปิดใช้งานจริง
1. Google Cloud Console: สร้างโปรเจกต์ เปิด Google Drive API สร้าง API key จำกัด HTTP referrer เป็นโดเมนเว็บของคุณ และจำกัดให้ใช้ได้เฉพาะ Drive API
2. ใน `config.js` ใส่ `apiKey` แล้วเปลี่ยน `demo: false`
3. ไดร์ฟ: แชร์โฟลเดอร์ `เอกสารประกอบ` เป็น "ทุกคนที่มีลิงก์ดูได้" และชีต `_สารบัญผลงาน` เป็น "ทุกคนที่มีลิงก์ดูได้" ตลอดช่วงประเมิน
4. GitHub: สร้างรีโป อัปโหลดไฟล์ทั้งหมด Settings > Pages > Deploy from branch (main, root)

## หลังประเมินเสร็จ
- ปิดการแชร์โฟลเดอร์ไดร์ฟ เว็บจะแสดงรายการต่อและขึ้นข้อความ "ปิดการเข้าถึงแล้ว"
- ในชีต ตั้ง "แสดงบนเว็บ" ของต้นฉบับ P06–P10 เป็น `ไม่` ถ้าไม่ต้องการให้เห็นอีก

## หมายเหตุสำคัญ
- "ชื่อและสถานะเท่านั้น" ซ่อนปุ่มเปิดไฟล์บนเว็บ แต่ไฟล์ยังเปิดได้ถ้ามีคนรู้ลิงก์ไดร์ฟของไฟล์นั้น ถ้าต้องการปิดจริง ให้เก็บไฟล์ไว้นอกโฟลเดอร์ที่แชร์
- ไฟล์ที่ชื่อไม่ขึ้นต้นด้วยรหัส (เช่น T01_...) เว็บจะไม่แสดง
